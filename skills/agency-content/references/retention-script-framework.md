# Retention script framework (short-form video)

Source: "Short-Form Storytelling (Writing Guide)" by Kallaway. Selected with
`agency-content --type reel --script-framework retention`. Use it for spoken,
talking-head or voiceover reels of 45-90 seconds that teach, argue or reveal
something. Keep the default `timeline` framework for short visual reels
(under ~30s), mood pieces and story-led films with characters.

## Structure

| # | Part | Length | Job |
|---|------|--------|-----|
| 1 | Hook | 1-2 sentences | Name the subject, create first curiosity |
| 2 | Lock-in zone | 2-4 sentences | Make them believe the rest is worth it |
| 3 | Body block 1 | 3-5 sentences | One non-obvious or contrarian point + support |
| 4 | Rehook 1 | 1 sentence | Reset attention, open a new loop |
| 5 | Body block 2 | 3-5 sentences | Second non-obvious point + support |
| 6 | Rehook 2 | 1 sentence | Only if block 3 runs |
| 7 | Body block 3 | 3-5 sentences | Optional |
| 8 | Closing | 1-2 sentences | Optional; only when there is no CTA |
| 9 | CTA | 1 sentence | Ramp to more value on the same topic |

## Principles

- Cut fluff. Keep it as short as the idea allows. 45-90s is the range, not a target.
- Clear logic flow: every sentence connects to the last or plainly starts a new thread.
- Tease the value as early as possible.
- Simple words whose meaning is already obvious. Clarity beats cleverness.

## Hook: the Four S's

- **Subject**: the topic is clear in the first sentence.
- **Stakes**: a reason this viewer must keep watching.
- **Simple**: plain words.
- **Superclear**: short, punchy sentence structure.

The brand archetype hook guidance and the universal anti-AI rules in `voice.py`
still apply: no stock hooks ("Most people don't know...").

## Lock-in zone

Pick one move, and name it in the brief:

- Tease proof (yours or others').
- Tease the transformation or emotional payoff.
- Clarify contrast with the common belief.
- Magic box: name an unknown term, method or framework they want to learn.
- Objection handling: dismiss their main objection before they raise it.
- Double down on the hook's claim.

Exit feeling: "I have to keep listening."

## Body blocks

Each sets up a non-obvious frame, then 2-4 sentences of facts, examples or
reasoning that defend it. Aim for two blocks: two hits of non-obvious value
drive follows.

## Rehooks

Attention lasts about 20-25 seconds. A single sentence between blocks resets
it through contrast or a new open question. Generic transitions read as
forced; write one that only works for this topic.

## Closing and CTA

Closing is a 1-2 sentence takeaway, used only when there is no CTA. The CTA
should be a value ramp tied to the topic (lead magnets work best). Running a
CTA on every video lets you measure conversion.

## House rules that still apply

- The post caption complements the script; it never restates its stat, story
  or CTA the same way.
- Brand-specific constraints (e.g. RankUp case-study rules, Kerr awareness-only
  briefs) override this structure where they conflict.
