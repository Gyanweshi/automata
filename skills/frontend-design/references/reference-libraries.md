# Design reference libraries

Look at these before setting the direction for any deck, presentation, brand guide,
mood board or other visual design. Use them to learn structure, rhythm and layout.
Never copy a reference's content, imagery, brand or wording into client work.

| Library | Use it for | Access |
|---|---|---|
| [deck.gallery](https://www.deck.gallery/) | Real-company strategy, pitch, report, capabilities and sales decks; single-slide view for layout ideas | First ~6 slides and a written per-slide summary are public; full decks need Pro (then use their official MCP). Behind Cloudflare: open it in a normal browser, never script around the check. |
| [Chronicle gallery](https://chroniclehq.com/gallery) | Data storytelling, keynote talks and case studies, filtered by category (Pitch, Strategy, Case Studies, Proposal, Branding…) | Full decks public, no login. |
| [Branding Style Guides](https://brandingstyleguides.com/) | Brand guideline PDFs from 1963 to 2026; search by industry, region, size and year | Free login, held in the saved browser-act browser `design-references`. The download button is JS: the file is `/download/?idm=<data-post-id of a.ddlBtn>`, fetched inside the logged-in page. |

## How to use them

1. Pick 3–5 references that match the brief's category and audience, such as an
   insurer's guide for an insurer or a SaaS sales deck for a SaaS pitch. Search
   Branding Style Guides by industry and region; filter deck.gallery and Chronicle by category.
2. Look at the whole structure (contact sheet or slide grid), not only the cover.
3. Write down what to take as patterns: section order, how evidence is shown, the
   recurring device, the rhythm of dense and quiet slides. Record them in the brief.
4. Reference files worth keeping (guide PDFs, contact sheets) go in the vault next to
   the note: `Research/Deck_References/Guides/`. `workspace/` is cleaned regularly, so
   it holds only disposable scraping output. Respect any "confidential" or
   "internal use" marking: read it, never show or quote it.

Already-studied references and client-matched picks are in the vault at
`Research/Deck_References/`. Patterns drawn from them are in
[deck-patterns.md](deck-patterns.md); brand-guide structure is in
[../../agency-orchestrator/references/brand-guide-checklist.md](../../agency-orchestrator/references/brand-guide-checklist.md).
