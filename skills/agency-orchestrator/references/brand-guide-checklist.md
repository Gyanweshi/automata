# Brand guide checklist

Drawn from five guides read in full on 2026-11-11: Matter Insurance 2023 (34 pp),
Liberty Mutual 2020 (108 pp), Jana Small Finance Bank 2018 (146 pp), Cohance
Lifesciences 2025 (97 pp) and Onset Homes 2022 (32 pp). Details are in the vault at
`Research/Deck_References/`. Use this list at onboarding to see which parts of the
client's brand system exist, which are missing and which must be decided before
production. It also works as the outline when the agency writes a brand guide.

Size the guide to the client: 30–35 pages for a startup or small business, 90–150 pages
for a company with branches, stationery and signage.

## 1. Brand (always first)

- [ ] Promise / mission, in one line
- [ ] Values
- [ ] Personality
- [ ] Voice, written as do/don't pairs with real example lines
- [ ] Who the customers are
- [ ] Messaging: approved headlines or verbatim lines, if any

## 2. Visual assets

- [ ] Logo: construction, clear space, minimum size, versions (colour, mono, reversed), misuse
- [ ] Logo with tagline and with partner logos
- [ ] Colour: primary and secondary values (HEX/RGB/CMYK), tints, accessible text and button pairs
- [ ] Typography: primary, secondary and system fonts, type scale, hierarchy
- [ ] **Indian languages** (any India-facing brand): Indic typefaces and the scripts it must cover
- [ ] Icons: one style, mono version, usage
- [ ] Photography: concept, colour treatment, subjects (people, people at work, objects, spaces), what to avoid
- [ ] Illustration, if used
- [ ] **One design device** beyond the logo (Matter's tape, Cohance's loop, Jana's curves): how it is built and used
- [ ] Mascot or character, with usage and licensing rules, if any

## 3. Communications

- [ ] Grid and logo placement on the grid
- [ ] Templates: social post sizes, presentation, email signature
- [ ] Sample communications in use

## 4. Applications (only what the client actually uses)

- [ ] Social profile and posts
- [ ] Website and app icon / favicon
- [ ] Stationery: business card, letterhead, envelope, ID card
- [ ] Advertising, print, outdoor
- [ ] Signage, spaces, merchandise
- [ ] Sector-specific items (finance: cheque books, cards, forms)

## 5. Housekeeping

- [ ] Version number and a "what changed" page
- [ ] Owner and contact for questions
