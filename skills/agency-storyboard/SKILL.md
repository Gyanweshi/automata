# Agency Storyboard Agent

You are the storyboard agent. When the user runs `/agency storyboard`, create visual storyboards and AI generation prompts for brand content.

## Trigger

`/agency storyboard <brand-slug> <type> "<topic>" [--slides N] [--duration N] [--tool freepik_image|freepik_video|blender]`

Types: `carousel` | `reel` | `post` | `mood_board`
`/agency storyboard <brand-slug> <type> "<topic>" [--slides N] [--duration N] [--tool <tool>]`

Types: `carousel` | `reel` | `post` | `mood_board` | `image`

## Standalone Images (`--type image`)

Use `image` for a single, freestanding visual that isn't part of a storyboard/scene
sequence — e.g. an ultrarealistic hero shot, a product photo, a poster.

```bash
agency-storyboard --brand <brand-slug> --type image --topic "<subject>" \
  [--setting "<location/environment>"] [--action "<what the subject is doing>"] \
  [--composition "<camera angle / framing>"] [--use-case "<e.g. Instagram hero shot>"] \
  [--copy "<exact tagline text>"] [--copy-position "<e.g. lower left>"] \
  [--tool nano_banana_2|nano_banana_pro|gpt_image_2] \
  [--detail-mode concise|standard|verbose|cinematic_verbose] \
  [--aspect-ratio 4:5] --format prompts
```

- `--detail-mode cinematic_verbose` adds an ultrarealism micro-detail layer (surface
  wear, micro-textures, specular highlights, contact shadows) — use for hero/key
  visuals, not quick iterations.
- **Aspect ratio follows the use case.** If `--aspect-ratio` is omitted, it's derived
  from `--use-case` — "Instagram static post"/"carousel" -> 4:5, "Instagram story"/
  "reel"/"TikTok" -> 9:16, "LinkedIn post" -> 1.91:1, "YouTube thumbnail"/"banner" ->
  16:9, "Pinterest"/"poster" -> 2:3, "profile picture"/"square" -> 1:1. Always state
  the platform/placement in `--use-case` so the prompt and image come out correctly
  ratioed — don't default to a generic ratio when the destination is known.
- The prompt is built from the brand's visual identity (photography style, mood,
  colors, avoid-list) plus, if research has run, the market's Visual DNA
  (`pattern_interrupt_opportunity`, `color_palette_trend`) for a "stand out from
  competitors" steer.
- `--copy` renders an exact tagline/caption on the image in the brand's font and
  color (from `visual.fonts`/`visual.colors`), positioned via `--copy-position`.
  Treat this as a **preview/draft tool only** — useful for checking how a line of
  copy reads on the image before committing to a layout. It is not how final
  creatives should ship (see "Recommended Final-Asset Workflow" below).
- **Logos are not generated by the AI model.** `negative_prompt` always includes
  "logo", and even without that, models can't reproduce a brand's exact mark from a
  text description. Generate the clean creative, then overlay the brand's actual
  logo/wordmark/monogram asset (e.g. `data/outputs/content/<brand>/.../wordmark*.png`)
  in post-production. Only use reference-image grounding for logo placement if the
  generation tool explicitly supports multi-image input and the user asks for it.

### Recommended Final-Asset Workflow (Figma / Photoshop-editable)

For any creative that needs to be edited later (copy changes, localization,
re-cropping, logo swaps), don't bake text or logos into the AI-generated image.
Instead:

1. **Generate the photo clean** — call `standalone_image_prompt`/the CLI
   *without* `--copy`. This gives a pure background/scene image with no text
   or logo artifacts to fight with.
2. **Keep the logo as a separate asset** — use the brand's existing transparent
   PNG (wordmark/monogram, e.g. `data/outputs/content/<brand>/.../monogram-cream.png`).
   Don't composite it into the final flattened file if the destination is Figma/
   Photoshop — hand it over as its own layer/asset.
3. **Assemble the final layout in Figma or Photoshop** — place the clean photo,
   logo, and tagline as separate, independently editable layers (text in the
   brand's actual font via `visual.fonts`, logo at brand-appropriate scale/
   placement, e.g. top-left or bottom-right per brand convention). This is what
   makes the deliverable editable for future copy/localization changes.
4. Only use Pillow-based flattening (as done for one-off Altara delivery) when
   the user explicitly wants a single flattened PNG and does not need to edit it
   further.
- **Before writing/refining the prompt by hand**, read `skills/visual-image/SKILL.md`
  (and the model file it points you to — `nano-banana.md` or `gpt-image.md`) for the
  model-specific syntax, golden rules, and pattern libraries (e-commerce, fashion
  editorial, food/beverage, portrait-cinema, etc.). The CLI output is a strong draft;
  these references tell you how to push it to ultrarealistic quality and how to layer
  in additional elements iteratively (generate → edit → add detail, rather than
  re-rolling).
- For reels/video prompts (Seedance, Kling 3.0, Veo), read `skills/visual-video/SKILL.md`
  before finalizing — it covers cinematography (Murch's Rule of Six), shot structure,
  and per-model constraints (duration, dialogue/lip-sync, multi-shot).

## Steps

1. **Verify install**: `python3 -c "import agency_storyboard; print('OK')"`

2. **Load context** - before generating:
   - Read `$OBSIDIAN_VAULT_PATH/Brands/<brand-slug>.md`. This is the single source of truth for brand-specific visual direction, mood, photography style, and prior decisions.
   - Read the `## Memory` section carefully and build on what has already worked or been rejected.
   - Do not call `search_second_brain` for brand-specific context. Use vault search only for broad topic or reference research that is not already covered in the brand note.
   - If prior research or content exists in `workspace/research/<brand-slug>/` or `workspace/content/<brand-slug>/`, skim the latest relevant output before storyboarding.

3. **Generate the storyboard**:
   ```bash
   agency-storyboard --brand <brand-slug> --type <type> --topic "<topic>" [--slides 7] [--duration 30] [--tool freepik_image] --format markdown
   ```

4. **Read and enrich**: The output contains scene breakdowns and raw AI prompts. Your job:
   - Read each scene description and enrich the visual details based on the brand's photography style and mood.
   - Refine the generation prompts so they are more specific, vivid, and brand-appropriate.
   - Add creative direction notes for each scene.

5. **Freepik MCP integration**: After generating prompts, you can immediately generate images using the Freepik MCP tools already configured in this workspace:
   - For images: use `mcp__freepik__create_image_mystic` or `mcp__freepik__text_to_image_mystic_sync`.
   - For videos: use `mcp__freepik__create_video_kling_2_1_std` or `mcp__freepik__create_video_kling_2_1_pro`.
   - Use the `positive_prompt` from the storyboard output as the prompt parameter.
   - Check status with `mcp__freepik__get_mystic_task_status` or `mcp__freepik__get_kling_2_1_task_status`.

6. **Output**: Present the storyboard to the user as:
   - Scene-by-scene visual direction
   - Refined generation prompts ready to paste into any AI tool
   - Option to generate with Freepik immediately

## Aspect Ratios by Format

| Format | Recommended | Use |
|--------|-------------|-----|
| Instagram carousel | 4:5 (1080x1350) | Freepik image |
| Instagram reel | 9:16 (1080x1920) | Freepik video |
| Instagram post | 1:1 (1080x1080) | Freepik image |
| LinkedIn carousel | 1:1 or 4:5 | Freepik image |
| LinkedIn post | 1.91:1 (1200x628) | Freepik image |

## Tool Selection

- `freepik_image` - best for carousels and static posts (uses Mystic model)
- `freepik_video` - best for reels (uses Kling 2.1)
- `blender` - for 3D visualization (uses Blender MCP, already configured)
- `generic` - tool-agnostic prompts for any AI generator

## MCP Integrations

Agent-scoped MCP configuration is stored in `mcp/agents/storyboard.json`.

- **Freepik FastMCP** (`FREEPIK_API_KEY`) - search Freepik assets and generate Mystic/Kling visual assets.
- **Blender** - create and inspect 3D storyboard scenes when Blender and its MCP addon are running.
- `nano_banana_2` / `nano_banana_pro` - standalone ultrarealistic images, real-place
  grounding, extreme aspect ratios (Gemini 3 Flash/Pro Image — see `skills/visual-image`)
- `gpt_image_2` - standalone images needing dense/small text, UI mockups, brand
  assets, or identity-preserving edits (5-slot prompt — see `skills/visual-image`)
- `seedance` / `kling_3` / `veo` - standalone video prompts (see `skills/visual-video`)

## MCP Integrations

MCP servers are configured per-machine in `~/.claude.json` (`freepik`, `apify`) or
per-project in `.mcp.json` (`figma`). There is no separate
`mcp/agents/storyboard.json` file in this repo.

- **Freepik FastMCP** (`FREEPIK_API_KEY`) - search Freepik assets and generate Mystic/Kling visual assets.
- **Blender** - create and inspect 3D storyboard scenes when Blender and its MCP addon are running.
- **Figma** (`.mcp.json`, official remote server at `https://mcp.figma.com/mcp`,
  OAuth login on first use) - read Figma file/frame context and write new
  layers/frames back to the canvas. Use this for the "Recommended Final-Asset
  Workflow" above: place the clean generated photo, the brand's logo asset, and
  an editable text layer for the tagline as separate layers in a Figma frame,
  rather than flattening everything into one PNG.

## Standalone Use

This agent can run without research data. If research exists in the workspace, it auto-loads it to inform scene themes.
