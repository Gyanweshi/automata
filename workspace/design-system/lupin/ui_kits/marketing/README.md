# Lupin Marketing UI Kit

A high-fidelity recreation of a Lupin-style **marketing surface** — the home of a global pharma brand. Built from the design tokens (no codebase or Figma was provided, so this is an interpretation, not an extraction).

## Components
- `Header.jsx` — sticky translucent header with primary nav and CTA.
- `Hero.jsx` — split hero with petal-masked image and lime keyline.
- `StatStrip.jsx` — four headline stats on the navy ground.
- `TherapyAreas.jsx` — grid of therapy-area product cards.
- `CalloutBand.jsx` — full-bleed callout with single accent CTA.
- `Footer.jsx` — multi-column navy footer.

## Interactivity
- Header CTA opens a faux "Find a product" search overlay.
- Therapy cards expand with a brief description on click.

## What this is not
A production code drop. Components are cosmetic — no real routing, real data, or real form handling. They exist to make the design system **tangible** in a typical marketing context.
