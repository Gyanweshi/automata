Prepared by Instinct, 2026-09-07. Removes the Perplexity, Freepik, and CapsuleHub
MCP servers (user request: "remove the mcps like perplexity, freepik, they are
redundant"; user confirmed "remove capsulehub, keep the rest") and refreshes the
documentation across the repo.

## Apply

```bash
cd automata
git apply /path/to/automata-mcp-cleanup.patch
git rm -r packages/freepik-fastmcp
git add -A
git commit -m "Remove redundant Perplexity, Freepik, and CapsuleHub MCP servers; refresh docs

- Drop perplexity from mcp/agents/research.json (overlaps firecrawl + Deep Research web search)
- Drop freepik-fastmcp from mcp/agents/storyboard.json and delete the vendored
  packages/freepik-fastmcp server (overlaps higgsfield, magnific, Image Agent)
- Drop capsulehub (mcp-remote bridge to Tilantra; manual-only, never in the manifests)
- bootstrap.sh / setup-mcp.ps1: drop vendored-freepik sync, perplexity and
  mcp-remote npm pin checks, and FREEPIK_API_KEY/PERPLEXITY_API_KEY/CAPSULEHUB_API_KEY key checks
- env.example: drop FREEPIK_API_KEY, PERPLEXITY_API_KEY, CAPSULEHUB_API_KEY
- .github/workflows/security.yml: drop freepik-fastmcp from bandit scan paths
- README.md: fix stale agents/swarm references (now agents/openedswarm_core),
  correct .mcp.json description, update MCP server table, skills list, API key
  table (PEXELS/PIXABAY/UNSPLASH), packages table, and quick-start commands
- AGENTS.md / CLAUDE.md: sync MCP assignments and tables
- skills: agency-research (drop Perplexity bullet), agency-storyboard (replace
  Freepik MCP generation step, consolidate stale duplicate MCP section),
  agency-orchestrator (reword Freepik MCP handoff line)"
```
